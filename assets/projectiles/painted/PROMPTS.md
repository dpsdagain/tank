# Transparent painted projectile prompts

The original visual concepts were generated in Google Flow. These production RGBA assets were generated with the built-in image generation tool using the Flow boards as visual references. The source PNGs are preserved unchanged. No CLI or API-key fallback was used. Each request used transparent_background=true.

STRICT side-on orthographic profile, facing RIGHT. Genuine transparent RGBA background, no background scenery, no ground, no floor shadow, no grid, no checkerboard, no labels or text, no UI, no border, no other weapons. Preserve generous transparent gutters on every side; do not crop the art. It must stay recognizable when reduced to about 35 pixels wide. Nose points exactly right and body axis is horizontal. Full rocket centered. Body only: NO exhaust flame, smoke, streaks or trail, because the game will animate these separately. Keep the detailed model large, taking about 65 percent of the image width and 30 percent of its height.
